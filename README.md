# Two-Nucleon Schrödinger Lab

Interactive solver of the radial Schrödinger equation for the deuteron, np, pp (with Coulomb) and nn systems, and slow-neutron scattering on ortho/para-H₂.

Live site: https://sarveshphy.github.io/deuteron-lab/
